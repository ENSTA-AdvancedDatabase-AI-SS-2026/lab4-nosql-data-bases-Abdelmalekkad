# Rapport TP5 - Benchmark
## Résultats
- Redis: Plus rapide pour les accès clé-valeur.
- Cassandra: Meilleur débit d'écriture asynchrone.
- MongoDB: Équilibré pour les documents complexes.

## Recommandation
- Utiliser Redis pour le cache.
- Utiliser Cassandra pour l'ingestion IoT massive.
- Utiliser MongoDB pour les dossiers médicaux structurés.
- Utiliser Neo4j pour les réseaux sociaux et recommandations.
